Causal Forests

A machine learning enhancement for experiments and A/B tests

Drop in an experiment and see which segments actually respond - the average effect, pulled apart by covariate, computed live in your browser. New to the idea? Read the primer →

1 · Add your experiment data
2 · Map your variables
3 · Average effect by segment
—

Each bar is the average treatment effect within that segment (mean outcome for treated minus control). Toggle covariates above to add or remove charts.

This computes segmented average effects directly in the browser. The full project uses honest generalized random forests (GRF) for smooth, per-unit CATEs - see the primer and the code.
